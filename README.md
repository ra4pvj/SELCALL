# HF Selcall

Приложение для macOS и Windows (7 SP1 и новее) для приёма и передачи КВ‑селкола **CCIR 493‑4**, совместимого с трансиверами CODAN (а также Barrett, Q‑MAC, Vertex). Работает через звуковую карту, к которой подключён трансивер.

Поддерживаются:
- **Selcall**: индивидуальный вызов, 4‑ или 6‑значные ID;
- **Message call**: короткое текстовое сообщение, до 64 символов;
- **звонок** при вызове на свой ID: повторяющиеся сигналы, как у трансиверов CODAN / Vertex Standard, и баннер «Ответить / Сбросить»; сигнал на выбор — двухтональный (CODAN), трель (Vertex), гудки или мелодия «Калинка»; звонок звучит у вас и **уходит в эфир** (через 1 с, передача ровно 5 с) — вызывающая станция слышит, что вызов принят;
- **управление передачей (PTT / CAT)**, как в HFP: VOX, линии RTS/DTR (с инверсией), CAT‑команды ICOM CI‑V, YAESU, YAESU‑OLD, KENWOOD, ELECRAFT; задержка PTT → сигнал и хвост; если PTT не включился — передача отменяется;
- **самоконтроль** на одно или несколько устройств сразу (эфир и/или своя передача) с отдельным уровнем — например, динамики ноутбука при трансивере на внешней звуковой карте; звонок звучит на этих же устройствах;
- отключаемая **пауза приёма на время передачи**, чтобы не декодировать собственный сигнал.

## Скачать

Готовые сборки — в [Releases](https://github.com/ra4pvj/SELCALL/releases): постоянные релизы `vX.Y.Z` и пре‑релиз `latest` (последняя сборка из `main`).

- `HFSelcall-macOS.zip` — macOS 13+, Apple Silicon и Intel;
- `HFSelcall-Windows-x64.zip` / `HFSelcall-Windows-x86.zip` — Windows 7 SP1 … 11, папка с `HFSelcall.exe`, без установки (см. `windows/README_WINDOWS.txt`).
- `HFSelcall-Linux-x64.tar.gz` — Linux x86_64 (glibc 2.35+), то же приложение, что и для Windows; нужна `libportaudio2`.

Сборки делает GitHub Actions (`.github/workflows/build.yml`). Windows‑версия собирается под Windows 7 так же, как HFP: Python 3.8.10, numpy 1.24.4 (работает и на процессорах без SSE4.2), sounddevice 0.4.6, PyInstaller 5.13.2 в режиме папки (onedir — без распаковки в %TEMP%). UCRT лежит рядом с exe. Каждый раз сборка проверяется самотестом готового exe и сканированием всех DLL/PYD и загрузчика на функции Windows 8+ (`windows/check_win7.py`). Чтобы выпустить релиз, поменяйте номер в файле `VERSION` (например, `0.3.1`) и отправьте в `main` — workflow сам создаст тег `v0.3.1` и релиз; можно и вручную тегом `vX.Y.Z`.

## Сборка

Нужен macOS 13 или новее и Xcode либо Command Line Tools:

```bash
xcode-select --install          # если ещё не установлены
git clone https://github.com/ra4pvj/SELCALL.git
cd SELCALL
./scripts/build-app.sh
open "build/HF Selcall.app"
```

Скрипт собирает release‑версию и прогоняет самопроверку кодека (`selcall-cli selftest`). Затем он упаковывает `build/HF Selcall.app`, подписывает его ad‑hoc и делает архив `build/HFSelcall.zip`.

Если `.app` перенесён на другой Mac, при первом запуске откройте его через правый клик → «Открыть»: приложение не нотаризовано.

При первом нажатии «Приём» macOS спросит доступ к микрофону, то есть к звуковому входу. Без этого доступа приём не работает.

Альтернатива: открыть `Package.swift` в Xcode и запускать схему `HFSelcall`.

## Использование

1. Укажите **Мой ID**, выберите **Вход** и **Выход** (звуковая карта или интерфейс трансивера).
2. **Приём**: слушать эфир. АПЧ сама находит сигнал в полосе 1000–2600 Гц и понимает USB/LSB.
3. **Кому** + **Вызов**: отправить селкол. Текст + **Отправить** (⌘↩): отправить сообщение.
4. **WAV**: сохранить вызов в файл или декодировать запись (⌘O).
5. Двойной клик по строке журнала подставляет отправителя в поле «Кому».

Передача идёт на выбранный выход. Трансивер переводится на передачу (⚙︎ → «Управление передачей (PTT / CAT)», перенос `hfpager_ptt.py` из HFP):
- **нет**: VOX или внешний PTT; «Задержка PTT/VOX» — тишина перед сигналом;
- **RTS / DTR / RTS+DTR**: PTT линией COM‑порта (Digirig, SignaLink‑подобные), с инверсией;
- **ICOM** (CI‑V `FE FE <адрес> E0 1C 00 01/00 FD`, адрес по модели или вручную), **YAESU** (`TX1;`/`TX0;`), **YAESU‑OLD** (`00 00 00 00 08/88`), **KENWOOD / ELECRAFT** (`TX;`/`RX;`).

«Тест PTT» включает передачу на 1 с. PTT снимается при остановке, ошибке и выходе; есть сторожевой таймер. CAT‑команды составлены по документации и на трансиверах не проверялись.

**Самоконтроль** (⚙︎): эфир и/или своя передача сразу на несколько устройств с отдельным уровнем.

При вызове на свой ID звучит звонок на устройствах самоконтроля (если не выбраны — на системном выходе); тип сигнала, громкость и длительность настраиваются. Автоматический ответ в эфир не передаётся.

Длина преамбулы задаётся в ⚙︎. Для станций в режиме сканирования она должна быть не меньше цикла сканирования, обычно 6–12 с.

```bash
swift run selcall-cli encode --to 1234 --from 5678 --msg "PRIVET 73" -o msg.wav
swift run selcall-cli decode msg.wav
```

## Протокол (кратко)

- FSK 100 бод, сдвиг 170 Гц, тоны 1700 Гц («0») и 1870 Гц («1»), центр 1785 Гц (в USB).
- Символ 10 бит: 7 информационных (младший бит первым) + 3 проверочных (число нулей в информационных, старший бит первым).
- Каждый символ передаётся дважды, DX и RX; RX‑копия отстаёт на 5 символов.

Кадр выведен из реальной записи `testdata/SELCALL_from_1111_to_1234.wav` (вызов 1111 → 1234):

```
точки ~6 с
DX: 125 125 125 125 125 125 120 12 34 100 11 11 117 117 117
RX: 109 108 107 106 105 104 120 120 120 12 34 100 11 11 117
     фазировка               F   адрес  кат. свой ID  EOS
```

- F = 120: format specifier (индивидуальный вызов); 100 = routine.
- EOS: 117 = нужен ACK, 122 = это ACK, 127 = конец.
- Символа ECC в записи нет. Достоверность приёма проверяется совпадением копий DX и RX.
- Кодер передаёт ровно такой кадр. Декодер понимает и его, и вариант ITU‑R M.493 (8 RX фазировки, F дважды, ECC).

**Не подтверждено.** Раскладка текста в CODAN Message call не опубликована. Сейчас каждый символ текста передаётся отдельным 7‑битным символом ASCII между своим ID и EOS. Нужна запись реального сообщения с CODAN. Менять надо `messageToSyms` / `symsToMessage` в `Selcall.swift` (и `msg_to_syms` / `syms_to_msg` в Python).
