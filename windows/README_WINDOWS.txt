HF Selcall для Windows
======================

Приём и передача КВ-селкола CCIR 493-4, совместимого с трансиверами CODAN (Barrett, Vertex Standard).

Системы: Windows 7 SP1, 8, 8.1, 10, 11.
  HFSelcall-Windows-x64.zip — для 64-битной Windows.
  HFSelcall-Windows-x86.zip — для 32-битной Windows (подходит и для 64-битной).
На Windows 7 нужны SP1 и обновление KB2533623 (обычно уже установлено через Windows Update).
Библиотеки UCRT лежат в папке программы, обновление KB2999226 не требуется.
Сборка на Python 3.8 и NumPy 1.24 — работает и на старых процессорах без SSE4.2/POPCNT.

Запуск: распакуйте архив ЦЕЛИКОМ (папка HFSelcall) и запустите HFSelcall.exe внутри неё —
установка не нужна. Программа ничего не распаковывает во временную папку при запуске.
Если появится окно SmartScreen: «Подробнее» → «Выполнить в любом случае».

Работа
------
1. «Мой ID», «Вход» и «Выход» — звуковая карта или интерфейс трансивера (SSB, USB).
   Отключите «улучшения звука» Windows для этих устройств.
2. «Приём» — слушать эфир. АПЧ сама находит сигнал в полосе 1000–2600 Гц.
3. «Кому» + «Вызов» — Selcall. Текст + «Отправить» (Enter) — сообщение (до 64 символов).
4. Двойной щелчок по строке журнала подставляет отправителя в «Кому».
5. Ctrl+O — декодировать запись WAV.

Настройки → «Управление передачей (PTT / CAT)» (как в HF Pager / HFP):
  нет — VOX или внешний PTT; «Задержка PTT → сигнал» — пауза перед сигналом.
  RTS / DTR / RTS+DTR — PTT линией COM-порта (Digirig, SignaLink-подобные, самодельные);
      «Инверсия» меняет полярность.
  ICOM (CI-V FE FE <адрес> E0 1C 00 01/00 FD) — IC-7300 (94h), IC-705 (A4h), IC-7610 (98h) и др.,
      адрес можно ввести вручную.
  YAESU (TX1;/TX0;) — FT-991/A, FTDX-101/10, FT-710, FT-891, FT-450D.
  YAESU-OLD (00 00 00 00 08/88) — FT-817/818, FT-857, FT-897.
  KENWOOD / ELECRAFT (TX;/RX;) — TS-590, TS-480, TS-2000, K3, KX3 …
  «Тест PTT» включает передачу на 1 с без звука — используйте эквивалент нагрузки.
  Если PTT включить не удалось, передача отменяется. CAT-команды на трансиверах не проверялись.
  «Не принимать во время передачи» — не декодировать собственный сигнал.

Настройки → «Самоконтроль»: эфир (вход) и/или своя передача одновременно на одно или несколько
устройств, со своим регулятором уровня — например, динамики ноутбука, когда трансивер подключён
к внешней звуковой карте. Не отмечайте выход, идущий на трансивер.

Настройки → «Звонок»: при вызове на ваш ID звучат повторяющиеся сигналы
на устройствах самоконтроля (если не выбраны — на системном выходе), сверху окна появляется
полоса «Ответить / Сбросить» (Esc).

Внешнее устройство (сирена, лампа, реле): Настройки → «Внешнее устройство». При вызове на ваш ID
на линию RTS / DTR / RTS+DTR отдельного COM-порта (порт PTT использовать нельзя) подаётся «1»
на 1–60 с. Кнопка «Внешн.» на панели включает выход вручную, пока не нажмёте её снова.

Прослушивание эфира после вызова (чтобы услышать голосовое сообщение): вызов на ваш ID → ответ в эфир →
вход звучит на устройствах самоконтроля (или системном выходе) заданное время (5 с – 10 мин), затем
выключается. Кнопка «Слушать» на панели включает прослушивание вручную. Должен быть включён «Приём».

Настройки и журнал: %APPDATA%\HFSelcall\

Передача в эфир на КВ требует лицензии.
